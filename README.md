# Khushi's portfolio

Open `index.html` in a browser to view the site. It is a standalone page with no build step or external assets.

The content is based on the supplied resume. Before publishing it publicly, review the contact details and each work description for your comfort and your employer's sharing policies.

The design uses one fixed viewport with Home, Experience, and Highlights tabs, so visitors switch sections without a vertical page scroll. It also includes a custom initials graphic, responsive layout, detailed experience focus areas, visual highlight cards, and a light/dark theme toggle. The logo animates the name after page load, then blinks a blue block cursor; browsers with reduced-motion preferences get a static logo.

Update `index.html` if you want to change the target role, contact links, experience details, or highlights. The hero graphic can be replaced with a professional photo if you decide you want one.

The Standard Chartered descriptions are intentionally high level. Keep examples focused on transferable skills, and leave out internal project names, client or customer information, screenshots, architecture details, and non-public metrics.

## Publish with GitHub Pages

This is a plain static site, so the portfolio folder contents can sit at the root of a dedicated GitHub repository. A suitable repository name is `khushi-agarwal-portfolio`. Push `index.html` and this README to the `main` branch, then open **Settings → Pages** and choose **Deploy from a branch → main → /(root)**. The project site URL will follow `https://Khushi771.github.io/khushi-agarwal-portfolio/`. GitHub Pages publishes the site publicly, so review the portfolio content before enabling it.
